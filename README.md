Project Overview
This project contains the HTML and CSS files for the South African History Online website. 
It includes pages for Home, About Us, Contact Us, Education, and volunteer.
Changelog Part 2 Feedback 

what I did on Part 1 Feedback 
I Removed all <div> tags and replaced them with HTML5 semantic elements as instructed from the lecture <header>, <nav>, main, section, article, aside, footer in all Five HTML pages to make them easy to navigate and easy to read.
I also Removed all inline CSS and JavaScript.
I created a single external stylesheet style.css and linked it to all HTML pages.
The Semantic Navigation Implemented a semantic <nav> element containing an unordered list for the main menu and footer quick links.

 
 
 
 Part 2 CSS and Responsive Design 
For the External Stylesheet I created style.css with a CSS to re-establish a base style such as  standardized margin, padding, box-sizing, and font-family.

Typography and Visual Styles I did the typography scales using relative units rem.
A explained original styles for headings, paragraphs, links, forms, and buttons, added a pseudo-classes hover, focus, active for the website to include interactive elements. 
For the layout structure I used CSS Flexbox for the header and forms, Grid for the main content area and footer to create a responsive, structured layout.
For the Responsive design I added a media query at the 768px breakpoint with a on smaller screens, the navigation blocks vertically, footer switches to a single column, font sizes to adjust using relative units, and images scale using max-width of 100%.
